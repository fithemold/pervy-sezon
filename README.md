# Первый сезон

Гид по выбору первого мотоцикла: пошаговая дорожная карта для новичка.

**Сайт:** https://fithemold.github.io/pervy-sezon/

## Технологии
HTML и CSS, без JavaScript.

## Страницы
- `index.html` — главная: дорожная карта, калькулятор бюджета, класс мотоциклов, Yamaha R6, чек-лист
- `step1.html` … `step5.html` — подробные страницы пяти шагов
- `community.html` — карта мотошкол, вопросы и ответы, форма для историй
- `css/style.css` — стили и анимации
- `assets/` — фото R6 и PDF-чек-лист
